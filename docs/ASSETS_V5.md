# V5 documentation visuals

All files under `docs/assets/screenshots/` were copied from real V5 screenshots supplied by the project owner. `product-tour.gif` assembles those screenshots into a full-frame carousel; it is not a screen recording of a running agent. `replay-showcase.gif` adds colored callouts over a real screenshot. `hero-banner.png` is a custom collage of actual V5 screenshots. These assets should **not** be described as live recordings.

The screenshots contain the `resolveos-llm (scripted)` label. That means they capture a demonstration/evaluation mode, not measured inference from Gemini or vLLM. Do not remove that qualification from the README.

To refresh the images, capture full-width screenshots from a safe demo database with no secrets, then replace the four PNG files and regenerate the carousel. Do not include API keys, terminal history containing passwords, or real customer records in GitHub assets.
